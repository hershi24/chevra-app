# מיין חברה

אפליקציית ווב לחבורה קרובה של חברים נשואים: חברות לימוד, יומן זיכרונות, צ׳אט בסגנון Google Chat, ואישורי הגעה בלחיצה אחת מהמייל.

הממשק כולו בעברית ובכיוון RTL. במובייל זה מרגיש כמו אפליקציה (ניווט תחתון קבוע). בדסקטופ הניווט עובר לסרגל עליון עדין.

## הרצה מקומית

```bash
npm install
npm run dev
```

השרת עולה על [http://127.0.0.1:4327](http://127.0.0.1:4327).

### כניסה (בלי סיסמה)

במסך הכניסה מזינים **שם משתמש בלבד**. בהדגמה:

| שם משתמש | תפקיד |
| --- | --- |
| דוד | מנהל מערכת |
| משה | מגיד שיעור |
| יוסף, אברהם, יעקב, שלמה, נתן, חיים | חברי חבורה |

## מה יש באפליקציה

- **לוח ראשי**: החברה הקרובה, ספירה לאחור, מיקום, כיבוד, ואישור הגעה מהיר. כותרת החברה אופציונלית.
- **יומן החבורה**: עמוד לכל חברה, גלריה, נגן תמונות/וידאו/אודיו בדפדפן (בלי הורדה כפויה).
- **גלריה**: כל התמונות והסרטונים במקום אחד, עם סינון לפי סוג, תאריך העלאה ומעלה.
- **צ׳אט**: ערוצים (כללי, הודעות רשמיות, כיבוד, טיולים) ושיחות אישיות. ציטוט, תגובות, תיוג `@`, קבצים והודעות קוליות. עדכונים בזמן אמת דרך SSE.
- **הגדרות**: שיוך תפקידים, חברים, רקעי «חברה קודמת», שליחת הזמנות, ו־IVR.
- **הזמנת מייל**: כפתורי [מאשר הגעה] / [לא אוכל להגיע] עם טוקן ייחודי שמעדכן את מסד הנתונים בלי התחברות.
- **IVR / צילצול**: `POST /api/ivr` עם `phone` ו־`digits` (`1` מגיע, `2` לא מגיע). מחזיר גם TwiML.

## אחסון נתונים

ברירת המחדל היא קובץ JSON מקומי (`data/store.json`) כדי שהאפליקציה תעבוד בלי מפתחות.

### צ׳אט חי ב־Supabase

הדרך היציבה ביותר: כל הודעה נכתבת לטבלת `messages` ב־Postgres, וכל הלקוחות מקבלים אותה מיד דרך **Realtime postgres_changes**. חיבור הפרויקט בגיטהב לסופרבייס לא מחליף את המפתחות — האפליקציה קוראת אותם מ־`.env.local` או מההגדרות של השרת (Vercel וכו׳).

1. בסופרבייס: SQL Editor, הריצו `supabase/schema.sql` (או את המיגרציה ב־`supabase/migrations/`).
2. ב־Project Settings → API העתיקו ל־`.env.local` (ולסביבת הפרודקשן):

```
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
SUPABASE_SERVICE_ROLE_KEY=...
```

3. הפעילו מחדש את השרת. בהפעלה הראשונה הערוצים וההודעות מהקובץ המקומי יועלו לענן.

הכתיבה נשארת בשרת (service role). הדפדפן רק מאזין לשינויים.

קבצי מדיה נשמרים ב־`public/uploads` ומוצגים עם נגני HTML5. בפרודקשן עדיף Cloudflare R2 או Supabase Storage.

### מייל אמיתי

הגדירו `RESEND_API_KEY` ו־`RESEND_FROM`. בלי המפתח, המנהל מקבל קישורים לבדיקה במסך ההגדרות.

### IVR

```bash
curl -X POST http://127.0.0.1:4327/api/ivr \
  -H 'Content-Type: application/json' \
  -d '{"phone":"0501112233","digits":"1"}'
```

אם מוגדר `IVR_WEBHOOK_SECRET`, יש לשלוח `Authorization: Bearer …`.

## מבנה

```
app/                 # App Router, API, PWA manifest
components/          # ממשק עברי
lib/                 # טיפוסים, הרשאות, חנות נתונים, מייל
supabase/schema.sql  # סכמה לפרודקשן
public/uploads/      # מדיה שהועלתה
```

## הרשאות

1. **מנהל מערכת** — חברות, תפקידים, חברים, רקעים, מייל ו־IVR.
2. **מגיד שיעור** — צפייה באישורי הגעה, סיכומי שיעור, עדכונים רשמיים.
3. **חבר** — RSVP, יומן, העלאת מדיה, צ׳אט.
