# מיין חברה

אפליקציית ווב לחבורה קרובה של חברים נשואים: מפגשי לימוד, יומן זיכרונות, צ׳אט בסגנון Google Chat, ואישורי הגעה בלחיצה אחת מהמייל.

הממשק כולו בעברית ובכיוון RTL. במובייל זה מרגיש כמו אפליקציה (ניווט תחתון קבוע). בדסקטופ יש לוח ראשי עם תפריט צד.

## הרצה מקומית

```bash
npm install
npm run dev
```

השרת עולה על [http://127.0.0.1:4327](http://127.0.0.1:4327).

### כניסה (בלי סיסמה)

במסך הכניסה מזינים **שם משתמש בלבד**. בהדגמה:

| שם משתמש | תפקיד |
| --- | --- |
| דוד | מנהל מערכת |
| משה | מגיד שיעור |
| יוסף, אברהם, יעקב, שלמה, נתן, חיים | חברי חבורה |

## מה יש באפליקציה

- **לוח ראשי**: המפגש הקרוב, ספירה לאחור, מיקום, כיבוד, ואישור הגעה מהיר.
- **יומן החבורה**: עמוד לכל מפגש, גלריה, נגן תמונות/וידאו/אודיו בדפדפן (בלי הורדה כפויה).
- **צ׳אט**: ערוצים (כללי, הודעות רשמיות, כיבוד, טיולים) ושיחות אישיות. ציטוט, תגובות, תיוג `@`, קבצים והודעות קוליות. עדכונים בזמן אמת דרך SSE.
- **הגדרות**: שיוך תפקידים, חברים, רקעי «חברות קודמות», שליחת הזמנות, ו־IVR.
- **הזמנת מייל**: כפתורי [מאשר הגעה] / [לא אוכל להגיע] עם טוקן ייחודי שמעדכן את מסד הנתונים בלי התחברות.
- **IVR / צילצול**: `POST /api/ivr` עם `phone` ו־`digits` (`1` מגיע, `2` לא מגיע). מחזיר גם TwiML.

## אחסון נתונים

ברירת המחדל היא קובץ JSON מקומי (`data/store.json`) כדי שהאפליקציה תעבוד בלי מפתחות. סכמת Supabase מוכנה ב־`supabase/schema.sql` — Realtime, Storage ו־RLS.

קבצי מדיה נשמרים ב־`public/uploads` ומוצגים עם נגני HTML5. בפרודקשן עדיף Cloudflare R2 או Supabase Storage.

### מייל אמיתי

הגדירו `RESEND_API_KEY` ו־`RESEND_FROM`. בלי המפתח, המנהל מקבל קישורים לבדיקה במסך ההגדרות.

### IVR

```bash
curl -X POST http://127.0.0.1:4327/api/ivr \
  -H 'Content-Type: application/json' \
  -d '{"phone":"0501112233","digits":"1"}'
```

אם מוגדר `IVR_WEBHOOK_SECRET`, יש לשלוח `Authorization: Bearer …`.

## מבנה

```
app/                 # App Router, API, PWA manifest
components/          # ממשק עברי
lib/                 # טיפוסים, הרשאות, חנות נתונים, מייל
supabase/schema.sql  # סכמה לפרודקשן
public/uploads/      # מדיה שהועלתה
```

## הרשאות

1. **מנהל מערכת** — מפגשים, תפקידים, חברים, רקעים, מייל ו־IVR.
2. **מגיד שיעור** — צפייה באישורי הגעה, סיכומי שיעור, עדכונים רשמיים.
3. **חבר** — RSVP, יומן, העלאת מדיה, צ׳אט.
